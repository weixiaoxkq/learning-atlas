# KV 的位置编码、上下文与 Hidden State

> 从已有聊天提炼的学习笔记；已讲解不等于已掌握。

## 需要纠正的理解

KV Cache 不是“没有位置、没有上下文处理的原始历史”，也不是模型最终输出。

| 对象              | 保存的是什么                   |
| ----------------- | ------------------------------ |
| 初始 Embedding    | Token ID 查表得到的输入向量    |
| 某层 K/V          | 该层输入经过相应投影得到的表示 |
| 最终 Hidden State | 经过模型最后层计算后的表示     |

标准 RoPE 实现中，K 通常已经旋转，V 通常不直接旋转。第二层及之后的输入已包含之前层的注意力结果，因此 V 可以带有上下文信息。

## 为什么历史 KV 可复用

在固定前缀、参数与位置处理不变的因果推理中，后追加 Token 对历史位置不可见。其旧表示不会因后来 Token 改变，故相应 KV 可复用。

这不意味着改写前缀后还可无条件复用旧缓存。还需匹配模型、前缀、位置等条件。
