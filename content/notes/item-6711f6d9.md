# 请求、响应、流式输出与异常

> 待学习课程提纲：本节尚未开始。案例与实验均为计划内容，未记录完成或掌握。

## 本节要解决的问题

- 模型服务的请求和响应通常包含哪些信息？
- 流式返回与完整返回在应用处理上有何不同？
- 网络失败、服务错误、输出截断和格式错误应该怎样区分？

## 讲解顺序

1. 用服务无关的请求示意解释消息、参数、响应和结束状态。
2. 逐步拼接一份示意流式响应，观察中间片段与完整结果的区别。
3. 为常见失败分类，再讨论超时、取消、凭据保管与错误返回的职责。

## 贯穿案例

资料整理助手展示生成过程，但只有确认响应完成后才把结果交给后续校验。

## 可选小实验

使用准备好的成功、截断和网络中断响应样例，分别写出应用应进入的状态；初期无需真实 API 或付费调用。

## 观察与验收

能够把“请求成功到达”“响应完整结束”和“业务结果可用”分别判断。
