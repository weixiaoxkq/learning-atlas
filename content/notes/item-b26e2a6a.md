# 日语动词变形总览：构成与语感

## 理解框架

动词表达可以分层理解：先确定动词类别，再看基础活用，最后看后接成分增加了什么意义。礼貌、否定、过去、可能等可以组合，所以不能把所有组合都当成互不相关的新形式来背。

本笔记整理本次讲过的现代日语核心活用及常见组合，不是穷尽所有句型或古语变化的清单。日语动词不随“我、你、他”等人称改变形式。

## 三类动词

| 类别 | 例子 | 变化特点 |
| --- | --- | --- |
| 五段／一类 | 書く、読む、話す、眠る | 最后一个假名换段，部分形式发生音便 |
| 一段／二类 | 食べる、見る、寝る | 通常去掉る，再接相应词尾 |
| 不规则／三类 | する、来る | 单独记忆 |

寝る是一段动词，眠る是五段动词。不能看到る结尾就判断为一段；帰る、入る、走る、切る等都是五段动词。

## 核心形式总表

来る一列用假名显示读音变化。表中“禁止表达”是辞书形加な；ます形、ない形等采用日语教学中常见的命名方式，不等于传统语法中单独一个活用词尾。

| 形式 | 書く：写 | 寝る：睡 | する：做 | 来る：来 |
| --- | --- | --- | --- | --- |
| 辞书形 | 書く | 寝る | する | くる |
| ます形 | 書きます | 寝ます | します | きます |
| ない形 | 書かない | 寝ない | しない | こない |
| た形 | 書いた | 寝た | した | きた |
| て形 | 書いて | 寝て | して | きて |
| ば形 | 書けば | 寝れば | すれば | くれば |
| 意向形 | 書こう | 寝よう | しよう | こよう |
| 命令形 | 書け | 寝ろ／寝よ | しろ／せよ | こい |
| 禁止：辞书形＋な | 書くな | 寝るな | するな | くるな |
| 可能形 | 書ける | 寝られる | できる | こられる |
| 被动形／受身形 | 書かれる | 寝られる | される | こられる |
| 使役形 | 書かせる | 寝させる | させる | こさせる |
| 使役被动形 | 書かせられる／書かされる | 寝させられる | させられる | こさせられる |

表中是形态对照，实际能否自然使用某一形式，还取决于动词意义、句中角色和语境。尤其不能把所有られる都机械翻译成“被”。

## 各形式增加的意思与语感

### 辞书形、ます形与ない形

- **辞书形是非过去，不等于正在。**「毎日、日本語を勉強する」表示习惯；「今日は早く寝る」可以表示今天的安排或打算。普通体常用于熟人聊天、日记、文章，本身不等于粗鲁。
- **ます形增加礼貌感。**「今日は早く寝ます」与普通体基本说同一件事，但对听者更客气；ます本身不表示想要、能够或正在。
- **ない形否定动作或状态。**「今日は寝ない」是不睡，具体是否出于主动决定要看上下文；「寝られない」才是否定睡的可能性。

### た形与て形

**た形**常把事情作为已发生或已完成的事来讲：

> 昨日は早く寝た。  
> 昨天很早就睡了。

但不总能直接译成过去：

> ご飯を食べたあとで、出かけます。  
> 吃完饭以后出门。

吃饭可能尚未发生；食べた表示它相对于出门先完成。

**て形**主要连接后面的成分，连接关系可包括先后、方式、原因等：

> ご飯を食べて、寝る。  
> 吃饭，然后睡觉。

て形本身不表示正在。食べている可以表示正在吃，寝ている可以表示睡着，結婚している表示已婚状态。ている可表达进行、结果状态或习惯，不能统一套成“正在”。

### 可能形

可能形既可表示能力，也可表示条件允许：

> 日本語が読める。——能读日语，有这个能力。  
> 明日はゆっくり寝られる。——明天可以好好睡，时间或条件允许。

寝れない是寝られない省去ら的常见口语形式；详见[寝る与眠る及寝れない](topic:item-8543033c)。

### 被动形与られる的多义

被动从承受动作、受到影响的一方来叙述：

> 先生に褒められた。——被老师表扬了。  
> 友達に笑われた。——被朋友笑话了。

被动本身不一定负面。日语还可以用被动突出某件事对自己造成影响：

> 赤ちゃんに泣かれて、眠れなかった。  
> 宝宝哭闹，弄得我没睡着。

这里不是“我被哭了”，而是宝宝哭影响到了我，常带困扰感。

| られる相关用法 | 例子 | 含义 |
| --- | --- | --- |
| 可能 | この魚は食べられる。 | 这条鱼可以吃 |
| 被动 | 魚が猫に食べられた。 | 鱼被猫吃了 |
| 尊敬 | 先生はもう帰られました。 | 老师已经回去了 |
| 自发，限部分动词 | 昔のことが思い出される。 | 不由得想起往事 |

### 使役与使役被动

**使役**表示促成、要求或允许别人行动，不能一律解释成强迫：

> 母は子どもに野菜を食べさせた。——妈妈让孩子吃了蔬菜。  
> 子どもを自由に遊ばせる。——让孩子自由玩耍。

**使役被动**表示自己被要求去做，常带不得已的感觉：

> 上司に残業させられた。  
> 被上司要求加班了。

する＝做；させる＝让别人做；させられる＝自己被要求做。不满的程度仍取决于语境。

### 意向、命令与禁止

| 表达 | 主要语感 |
| --- | --- |
| もう寝よう。 | 对自己可表示打算或下决心；对别人可表示提议一起睡 |
| 一緒に帰ろう。 | 邀请一起回去 |
| 一緒に帰りましょう。 | 礼貌地提议一起回去 |
| 早く寝ろ。 | 快睡，直接命令 |
| ここで寝るな。 | 别在这里睡，直接禁止 |
| 早く寝てください。 | 请早点睡，请求表达 |

命令形、辞书形＋な很直接，常见于紧急指令、争吵、亲近关系、运动等场景。寝よ、せよ较偏书面、规章或郑重命令；日常更常听到寝ろ、しろ。

## 四种条件表达

下表是入门理解角度，不是全部用法或绝对的替换规则。

| 表达 | 构成示例 | 语感重点 | 例句 |
| --- | --- | --- | --- |
| ば | 書く→書けば | 突出条件：满足什么条件，结果才成立 | 練習すれば、上手になる。练习就会进步。 |
| たら | 書いた＋ら | 如果发生了，或等发生之后 | 家に帰ったら、電話して。到家后给我打电话。 |
| と | 書く＋と | 常规、规律或自然接着发生的结果 | このボタンを押すと、ドアが開く。按这个按钮，门就开。 |
| なら | 書く＋なら | 接受某个前提，再提出判断或建议 | 日本に行くなら、京都がおすすめ。要去日本的话，推荐京都。 |

> 日本に行ったら、連絡して。  
> 到日本之后，联系我。

> 日本に行くなら、切符を早めに買ったほうがいい。  
> 如果打算去日本，最好早点买票。

后一例中的买票发生在去日本之前；なら接受“打算去日本”这个前提后给建议，并不要求先去日本。たら在前一例中着重前项成立之后。四种条件存在搭配限制，不能随意互换。

### 把整句话作为假设前提

若要表达“假设这整句话成立，那么……”，可以使用**普通形句子＋としたら／とすれば／とすると**，更明确地设定假说时也可以用と仮定すると。

| 表达 | 主要语感 | 使用倾向 |
| --- | --- | --- |
| としたら | 假设一下，如果真是这样 | 对话、设想场景中自然 |
| とすれば | 若以此为前提，那么…… | 偏逻辑推论，书面论述常见 |
| とすると | 按这个前提推下去，那么…… | 分析、计算、推理中常见 |
| と仮定すると | 明确说“假定……” | 较正式，报告、论文、说明中常用 |

这是语感与使用倾向，不是口语、书面的严格分界；口语里也会用とすれば。

将「彼が明日来ない」（他明天不来）作为前提：

> もし彼が明日来ないとしたら、どうする？  
> 假如他明天不来，怎么办？

这是邀请对方设想一个情境的对话说法。としたら把“先假设一下”的感觉凸显出来。

> 彼が明日来ないとすれば、計画の変更が必要になる。  
> 假如他明天不来，就需要修改计划。

这是以假设为前提进行分析的说法。若要明确强调假定，可以说「彼が明日来ないと仮定すると、……」。

### 整句假设的接续

前面的判断通常用普通形，否定与过去可以保留：

| 原来的判断 | 接成假设 |
| --- | --- |
| 彼が来る。 | 彼が来るとしたら |
| 彼が来ない。 | 彼が来ないとしたら |
| 彼がもう帰った。 | 彼がもう帰ったとしたら |
| その話は本当だ。 | その話が本当だとしたら |
| 部屋が静かだ。 | 部屋が静かだとしたら |

名词、な形容词在としたら等前的基本肯定形式保留だ，例如学生だとしたら、静かだとしたら；接なら时则是学生なら、静かなら，不说学生だなら。关于だ更一般的接续规则，另见[だ的接续：为什么有时保留、有时不用](topic:item-d0046ec9)。

### 与日常なら的区别

普通聊天里，不需要突出设定假说时，なら往往就够了：

> 彼が来ないなら、先に始めよう。  
> 如果他不来，我们就先开始吧。

这里更像接受“他不来”这个前提，再作决定；来ないとしたら更突出“先假设他不来”。

这些结构通常结束的是**假设从句**，后面再接结果、判断或问题。口语也可以省略后半句：

> もし明日、雨だったら？  
> 要是明天下雨呢？

此处省略了“怎么办”等内容。もし加强假设感，真正把前句接成条件的是后面的だったら等形式；不是仅靠もし就完成接续。


## 基础变化规则

### 五段：换段

| 变化 | 書く的例子 |
| --- | --- |
| う段→あ段＋ない | 書かない |
| う段→い段＋ます | 書きます |
| う段→え段＋る：可能 | 書ける |
| う段→え段＋ば：条件 | 書けば |
| う段→え段：命令 | 書け |
| う段→お段＋う：意向 | 書こう |
| う段→あ段＋れる：被动 | 書かれる |
| う段→あ段＋せる：使役 | 書かせる |

注意：う结尾的动词否定变为わない，如買う→買わない；ある的普通否定是ない。

### 一段：去る接词尾

寝る去掉る后接：ない、ます、て、た、れば、よう、ろ、られる、させる等。对应寝ない、寝ます、寝て、寝た、寝れば、寝よう、寝ろ、寝られる、寝させる。

### て形与た形的音便

| 五段动词结尾 | て形词尾 | た形词尾 | 例子 |
| --- | --- | --- | --- |
| う・つ・る | って | った | 買う→買って／買った |
| む・ぶ・ぬ | んで | んだ | 読む→読んで／読んだ |
| く | いて | いた | 書く→書いて／書いた |
| ぐ | いで | いだ | 泳ぐ→泳いで／泳いだ |
| す | して | した | 話す→話して／話した |

例外：行く→行って／行った。一段动词直接去る接て／た，如寝て／寝た、食べて／食べた。

## 礼貌、否定与过去的组合

| 含义 | 普通体 | 礼貌体 |
| --- | --- | --- |
| 睡／要睡 | 寝る | 寝ます |
| 不睡 | 寝ない | 寝ません |
| 睡了 | 寝た | 寝ました |
| 没睡 | 寝なかった | 寝ませんでした |

这些是不同维度的组合，不必当成八套互无关系的规则。

## 常见后接表达

下列内容是基础形式后接其他成分构成的表达，并非全部都是单独的动词活用。

| 表达 | 例子 | 含义与语感 |
| --- | --- | --- |
| ます去掉ます＋たい | 寝たい | 想睡，通常表达自己的愿望 |
| ます去掉ます＋たがる | 子どもが帰りたがっている | 从外在表现判断孩子想回去 |
| ている | 本を読んでいる | 正在读；也可表示状态、习惯 |
| てある | 名前が書いてある | 有人写好了，结果保留着 |
| ておく | 予約しておく | 为之后做准备，提前预约 |
| てしまう | 全部食べてしまった | 全吃完了；也可能带后悔、意外 |
| てみる | 食べてみる | 吃吃看、尝试一下 |
| ていく | これから増えていく | 从现在往后继续变化 |
| てくる | 最近、増えてきた | 变化发展到现在 |
| てあげる | 私が友達を手伝ってあげる | 我为朋友做，带给予帮助的视角 |
| てくれる | 友達が手伝ってくれる | 别人为我或我方做，带受惠感 |
| てもらう | 友達に手伝ってもらう | 我得到、请到别人的帮助 |
| てほしい | 手伝ってほしい | 希望别人帮忙 |
| てください | 待ってください | 请求对方做 |
| てもいい | 帰ってもいい | 可以回去，许可 |
| てはいけない | 入ってはいけない | 不可以进入，禁止 |
| なければならない | 行かなければならない | 必须去，义务 |
| なくてもいい | 行かなくてもいい | 不去也可以，没有义务 |

### ます去掉ます后的连接与推测、传闻

| 接法 | 例子 | 含义 |
| --- | --- | --- |
| ます去掉ます＋ながら | 食べながら話す | 一边吃一边说 |
| ます去掉ます＋やすい | 読みやすい | 容易读 |
| ます去掉ます＋にくい | 読みにくい | 难读 |
| ます去掉ます＋すぎる | 食べすぎる | 吃得过多 |
| ます去掉ます＋そうだ | 寝そうだ | 看起来快睡着了 |
| 普通形＋そうだ | もう寝たそうだ | 听说已经睡了 |
| 普通形＋だろう | もう寝ただろう | 大概已经睡了吧 |

そうだ前的接法影响意思：寝そうだ＝看起来快睡着；寝るそうだ＝听说要睡；寝たそうだ＝听说睡了。

### 否定连接与较书面的形式

| 形式 | 例子 | 本例的语感 |
| --- | --- | --- |
| ないで | 朝ご飯を食べないで出かけた | 没吃早饭就出门，不做前项而做后项 |
| なくて | 眠れなくて、困った | 因为睡不着而困扰，连接原因 |
| ずに | 食べずに出かけた | 不吃就出门，相对偏书面；する→せずに |
| ぬ | 知らぬ | 不知道，较古风、书面；する→せぬ |
| まい | 二度と行くまい | 决心不再去；まい也可表示否定推测，较书面 |

ないで、なくて的用法不止表中这些。相关笔记：[しなくて、しないで与せずに的区别](topic:item-803fb196)。

## 日常口语缩约

| 完整形式 | 常见口语 | 含义 |
| --- | --- | --- |
| 寝られない | 寝れない | 睡不着、没法睡 |
| 寝ている | 寝てる | 正在睡、睡着 |
| 寝ていた | 寝てた | 当时在睡 |
| 食べてしまった | 食べちゃった | 吃掉了，可能带意外或后悔 |
| 読んでしまった | 読んじゃった | 读完了，具体情绪看语境 |
| 書いておく | 書いとく | 提前写好 |
| 行かなければ | 行かなきゃ | “必须去”时常用，句末可省略后半句 |

相关笔记：[〜てて：〜ていて的口语省略与くれてて](topic:item-765dccca)。

## 传统语法的六种活用形

这是按词尾连接方式划分的分类，不是六种独立语感。表中用現代語的假定形名称。

| 名称 | 書く的形式 | 主要作用 |
| --- | --- | --- |
| 未然形 | 書か／書こ | 接ない、れる、せる、う等 |
| 连用形 | 書き／書い | 接ます、たい、て、た等 |
| 终止形 | 書く | 结束句子 |
| 连体形 | 書く | 修饰名词，如書く人 |
| 假定形 | 書け | 接ば，如書けば |
| 命令形 | 書け | 直接命令 |

同属一类的不同形式有各自接续：例如書かない、書こう；書きます、書いて，不能任意交换。

## 用寝れなかった练习拆解思路

> 寝る：睡  
> → 寝られる：能睡  
> → 寝られない：不能睡  
> → 寝られなかった：当时不能睡、没能睡着  
> → 寝れなかった：上一形式的常见口语说法

寝ない否定的是“睡”，寝れない否定的是“能睡”。长词尾可以按增加的意义逐层拆解。
