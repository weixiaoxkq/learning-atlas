# 国：くに、こく与ごく的读法

## 随词识别读音

| 读法 | 例子 |
| --- | --- |
| くに（训读） | 国（くに）、国々（くにぐに）、国へ帰る（くにへかえる） |
| こく（音读） | 国際（こくさい）、外国（がいこく）、韓国（かんこく） |
| ごく（部分词中的浊音形式） | 中国（ちゅうごく）、天国（てんごく） |

不能把所有复合词中的「国」都读成こく，也不能只凭出现的位置机械推断。应连同具体词汇记忆；「国々」中的重复部分也有浊化。
