# 開ける・開く：あける／あく／ひらく的区别

## 基本区别

| 形式 | 自他 | 常见含义与例句 |
| --- | --- | --- |
| 開ける（あける） | 他动词 | 打开门窗、盖子等。ドアを開ける：把门打开。 |
| 開く（あく） | 自动词 | 门等处于打开、变开的状态。ドアが開く：门开了。 |
| 開く（ひらく） | 自他均有 | 展开、开展、开放等。本を開く：打开书；花が開く：花开；会議を開く：召开会议。 |

自动词「あく」不意味着“没有人操作”，而是句子从门等对象的变化来表达。

「ひらく」与「あける」不能仅按大小或自他动词划分。用于门时可能重叠，但书、会议等有各自惯用搭配。

## 開け／開き为什么不能只看字判断

- あける → 连用形「あけ」，如「あけます」。
- あく → 连用形「あき」，如「あきます」。
- ひらく → 连用形「ひらき」，如「ひらきます」。

「開け」单独出现时也可能是「あく」的命令形「あけ」，或「ひらく」的命令形「ひらけ」。必须结合原句和读音判断。

## 打开与关闭：按对象选择表达

中文“打开／关闭”在日语中没有一组适用于所有对象的动词。下面整理的是本次讨论的日常主要搭配，不代表所有词义或固定表达的穷举。

### 门窗：開ける／閉める；開く／閉まる

| 表达角度 | 打开 | 关闭 |
| --- | --- | --- |
| 人对对象做动作 | 開ける（あける） | 閉める（しめる） |
| 对象发生变化 | 開く（あく） | 閉まる（しまる） |

- 私がドアを開けた：我把门打开了。
- ドアが開いた：门开了。
- 私がドアを閉めた：我把门关上了。
- ドアが閉まった：门关了。

「を」在这些句子中标出动作对象；「が」标出发生变化的东西。自动词句不说明操作者，不意味着没有人操作。

窓を開ける／閉める（开关窗）、ふたを開ける／閉める（打开／盖上盖子）、引き出しを開ける／閉める（拉开／关上抽屉）都是常见搭配。

### 展开、合拢及文件操作：開く／閉じる

| 对象 | 打开／展开 | 关闭／合拢 |
| --- | --- | --- |
| 书 | 本を開く（ひらく） | 本を閉じる（とじる） |
| 伞 | 傘を開く（ひらく） | 傘を閉じる（とじる） |
| 眼睛 | 目を開く（ひらく）／開ける（あける） | 目を閉じる（とじる） |
| 电脑文件 | ファイルを開く（ひらく） | ファイルを閉じる（とじる） |
| 标签页 | タブを開く（ひらく） | タブを閉じる（とじる） |

「ひらく」「とじる」均可用于自他用法。例如「花が開く（ひらく）」「目が閉じる（とじる）」。展开／合拢是理解线索，文件等仍应按惯用搭配记忆。

门也可以用「ドアを開く（ひらく）」「ドアを閉じる（とじる）」，与「あける／しめる」有重叠；不能据此认为所有对象均可随意替换。

### 開く的读音与活用

| 原形 | ます形 | て形 | 过去式 |
| --- | --- | --- | --- |
| 開く（あく） | あきます | あいて | あいた |
| 開く（ひらく） | ひらきます | ひらいて | ひらいた |

- ドアが開いている（あいている）：门开着。
- ファイルを開いている（ひらいている）：正打开着文件。

同样的汉字写法需要根据对象与上下文判断读音。

### 灯、电视、空调与电源

- 電気をつける／消す（けす）：开灯／关灯。
- テレビをつける／消す：打开／关闭电视。
- エアコンをつける／消す：开／关空调。
- 電源を入れる（いれる）／切る（きる）：接通／关闭电源。

「パソコンの電源を入れる」是给电脑开机；「ノートパソコンを開く（ひらく）」可以表示把笔记本电脑展开、掀开，并不保证已开机。合盖与关机也不同，明确说关机可以用「シャットダウンする」。

### 应用程序与窗口

- アプリを開く（ひらく）／閉じる（とじる）：打开／关闭应用。
- アプリを起動する（きどうする）／終了する（しゅうりょうする）：启动／结束应用。

强调退出整个程序时，「終了する」更明确；关闭窗口未必等于程序退出。

### 锁、水龙头、瓶盖与包装

| 中文 | 日语 |
| --- | --- |
| 上锁 | 鍵をかける |
| 开锁 | 鍵を開ける（あける）／外す（はずす） |
| 打开水龙头 | 蛇口をひねる／開ける（あける） |
| 关紧水龙头 | 蛇口を閉める（しめる） |
| 放水／止水 | 水を出す（だす）／止める（とめる） |
| 打开／拧好瓶盖 | キャップを開ける（あける）／閉める（しめる） |
| 打开袋子 | 袋を開ける（あける） |
| 封上袋口 | 袋の口を閉じる（とじる）／封をする |

「鍵を開けてから、ドアを開ける」表示先开锁，再开门；两项动作有区别。

### 店铺及抽象用法

- 店を開ける（あける）／閉める（しめる）：开门营业／关门。
- 店が開いている（あいている）／閉まっている（しまっている）：店开着／关着。
- 会議を開く（ひらく）／終える（おえる）：召开／结束会议。
- 心を開く（ひらく）／閉ざす（とざす）：敞开心扉／封闭内心。

### 请求、状态与保持

| 意思 | 门 | 文件 |
| --- | --- | --- |
| 请打开 | ドアを開けてください | ファイルを開いてください |
| 请关闭 | ドアを閉めてください | ファイルを閉じてください |
| 请别关 | ドアを閉めないでください | ファイルを閉じないでください |
| 请先打开并留着待用 | ドアを開けておいてください | ファイルを開いておいてください |

文件用例中的「開いて」读「ひらいて」。

- ドアが開かない（あかない）：门不开／打不开，侧重对象未打开。
- ドアを開けられない（あけられない）：无法把门打开，侧重人不能完成动作。
