# 日常使用：聊天学习，结束后整理

## 你需要说什么

在这个项目的 Codex 聊天里，直接说：

| 你说                   | Codex 应做的事                                             |
| ---------------------- | ---------------------------------------------------------- |
| 我要学习数据库索引     | 先找已有内容，必要时创建主题和路径，再开始讲解             |
| 继续上次的内容         | 从未整理断点或正式学习位置接着讲，不从第一节重来           |
| 讲下一节               | 顺着路径前进，不要求把所有前置都打成已掌握                 |
| 这里没懂／再深入一点   | 围绕当前节点继续解释，不跳节                               |
| 这个知识点我已经掌握   | 记录你的明确确认，到整理时保存状态                         |
| 今天学到这里，整理一下 | 提炼本次内容、合并旧笔记、更新位置并构建网页，然后停止教学 |
| 先暂停，不整理         | 留下本机断点，下次从断点恢复                               |
| 提交并发布最新知识库   | 另外执行 Git 提交、推送及部署检查                          |

如果 Skill 没有自动触发，可以说：`使用 $learning-atlas，继续上次的内容。` AGENTS.md 也直接指向仓库中的技能文件，作为当前聊天的读取入口。

## 一个完整例子

你说“继续 AI 的内容”。Codex 读取 AI 主题、学习路径和记录位置；如果上次停在 MoE，就先从 MoE 接上。你可以追问、要求换个例子，也可以说“下一节”进入预训练。

每段实质教学后，只保存一小段本地会话摘要：讲过哪些节点、当前讲到哪里、哪些疑问还没有解决。此时网页仍是上一次整理的内容。

你说“整理本次学习”。Codex 读取本次会话和旧笔记，把新的理解、例子、纠正与疑问合并到对应 Markdown，更新正式位置。目录、思维导图和搜索由同一份内容重新构建。确认检查通过后，Codex 关闭会话并给出网页链接。

## 保存与恢复的范围

- 正式学习成果保存在 content/，适合由 Git 同步、备份和长期维护。
- 未整理断点保存在 `.learning/`，在同一个 checkout 换聊天可以恢复；它被 Git 忽略，不跨设备同步。
- 断点是语义摘要，不是逐字聊天记录。如果中断前没有成功保存摘要，不能保证恢复那部分细节。
- 关闭聊天或退出 Codex 不会自动运行整理。下次可以先说“继续上次未整理的内容”，再发整理命令。
- “整理到页面”表示更新本地源码与构建产物；GitHub Pages 只有在另行发布成功后才更新。开发预览会刷新源文件，构建预览需刷新页面；若没有运行服务器，Codex 应启动已有预览或给出启动命令。

## 已有内容与掌握状态

“讲过了”不表示“掌握了”。用户没有明确确认时，整理后的节点为 learning，网页显示“已有记录”。这不阻碍顺着路径继续，也不会重复要求学完所有前置。

用户追问不自动更改当前位置。整理时的位置是实际停止的节点，不提前标为下一节。若停止节点已明确掌握，下次续课定位会自动选择其后的未完成节点，避免重复讲解或从路线开头重来。对已经掌握的节点补充笔记，也不会自动把它降为未掌握。

## 冲突和失败

同一工作目录一次只维护一个会话。教学中不要同时由另一进程修改正式 content。整理命令发现正式文件在会话开始后发生变化会拒绝覆盖；Codex 需核对并合并，不能通过改摘要指纹跳过检查。

整理后的验证或构建失败会保留会话，修复并验证后再关闭。需要修正已保存笔记时，修改 finish 清单后重新运行 finish；命令只在没有外部改动时接受修订。相同整理清单重复运行不会重复写入。多文件写入有异常恢复，但不承诺并发编辑或进程被强制终止时的数据库事务保证。

## 给维护者的命令

你日常不需要手动填写这些文件，Codex 会依据 Skill 操作。

```sh
npm run study:context
npm run study:start -- --course COURSE_ID --topic TOPIC_ID
npm run study:start -- --next
npm run study:checkpoint -- --file .learning/checkpoint.json
npm run study:finish -- --file .learning/finish.json
npm run validate
npm test
npm run build
npm run study:close -- --session SESSION_ID
```

JSON 字段约定见 [Skill 会话格式](../.agents/skills/learning-atlas/references/session-format.md)。这些命令没有语言模型能力，笔记提炼与教学仍由 Codex 完成。

## 日语：随学随记

直接提出问题，例如「は 和 が 有什么区别」。先检索已有笔记，复用对应知识点；新问题归入语法、词汇、表达辨析或阅读笔记。说「整理本次学习」后保存到网页。同一知识点合并补充，不重复生成笔记。没有固定下一节，也不根据目录顺序安排教学。
